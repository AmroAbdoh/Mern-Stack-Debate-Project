Roles:

* Admin, Voter, Host

Voter:

* Can Join a Debate Instance by going to URL or scanning QR Code
* Can Vote post-debate or both -pre and post-  depending on debate format
* Can only vote when voting is available
* Can only vote once (mechanism to be decided)
* Can vote with, against, or abstain from voting, depending on format or debate session settings
* Cannot log in



Host:

* should create an account and log in before creating a session
* can start a session
* can change settings of the session (debate format, abstain possibility)
* each session must have:

  * Start time, either scheduled or start instantly
  * Time of each phase/ round depending on the format, can be changed in settings
  * Debate format (PF, LD)
  * The main statement, which voters can vote with or against
  * Team names
  * Team member names
  * contact info of team members (optional)
* can present a timer on a main screen presenting the time left for team/phase/voting (timer and all voter devices should be in sync. figure it out)
* can change/ add/ reduce time left for each phase
* Results are shown at the end, either by a trigger from the host or automatically depending on settings
* session pause/ resume
* export results as csv (optional)
* 



admin:

* view analytics of the website
* ban hosts
* cancel sessions
* unban hosts
* audit logs
